## 实现

在现有的显示器级前景位图上，按与绘制/输入相同的盒子顺序，从后向前处理：

1. 无重叠直接跳过，不更改原背景。
2. 对即将绘制的上层盒子，读取此前已绘制的下层像素。
3. 仅在重叠区域及模糊支持范围内，缩小采样并执行三次可分离方框滤波，近似高斯模糊。
4. 在上层圆角轮廓内用 SourceCopy 替换下层像素，避免留下锐利文字重影。
5. 最后绘制上层自身的染色、标题、图标和交互，保持清晰。

全部颜色通道与 alpha 以预乘格式同步滤波；不截图、不读回系统 HostBackdropBrush、不加入噪点。壁纸与桌面图标仍由原实时背景采样器处理。系统关闭高级透明效果时，原非亚克力绘制路径不受影响。

这是局部 CPU 位图原型，不是逐盒子的 GPU Composition 背景采样树。它只处理同一个显示器前景画布中已经绘制的盒子。
