# CrabDesk 1.0.0

CrabDesk 1.0.0 是首个面向 Windows 10/11 x64 的正式版本。它将桌面盒子嵌入 Explorer 桌面层，不使用全局置顶窗口；普通应用和全屏窗口可以覆盖盒子，返回桌面后盒子仍然可见。

## 从预发布渠道升级

- 本版本是**正式版（stable）**，不再是日期编号的预发布版本。
- 如果你正在使用日期编号版本（如 `20260924.01` / `20260924.02`），请**先升级到 `20260924.02` 或更高**，再通过应用内更新升级到 1.0.0。
  - 原因：`20260924.01` 及更早版本的版本比较把日期编号当作主版本号，会把 `1.0.0` 判定为更旧，从而不提示本次更新。该问题已在 `20260924.02` 修复。
  - 直接下载并运行 1.0.0 安装包不受影响。

## 主要功能

- 创建、移动、缩放、折叠、重命名和删除桌面盒子。
- 盒子分组只保存元数据，不复制文件、不创建真实子目录，也不改变桌面文件路径。
- 未分组项目继续使用 Explorer 原生位置和菜单；项目移入盒子后将对应原生图标停放到可视区域外，移出或退出时恢复。
- 支持网格与列表视图、名称/大小/类型/修改时间排序、图标尺寸与间距、标题样式、圆角、边框和选中颜色。
- 支持按项目类型、扩展名和名称通配符进行自动整理，并提供预览和批量撤销。
- 支持手动及每日布局备份、导入导出、保留策略和失败回滚。
- 支持文件夹映射盒子、只读模式、实时刷新以及离线重连。
- 支持全局快捷键和托盘快捷操作。
- 支持浅色、深色和跟随系统主题，以及托盘、单实例和开机启动。
- 通过 GitHub Releases 检查更新，并可在应用内下载、校验和启动安装；客户端不会保存 GitHub Token。

## 1.0.0 期间的主要修复

- **桌面「创建日期」排序**：此前无法识别这一排序方式，会静默退回名称排序，拖动新建文件后整个桌面被打回 A-Z；现在按文件创建时间正确排序，并与修改时间区分。
- **排序状态稳定性**：Explorer 短暂返回空排序读数时不再覆盖已知排序，也不再清空已保存的图标布局。
- **批量删除**：单个文件被占用不再中断整批删除；部分失败时明确列出已删除、失败与被跳过的项目；删除失败的项目不再被当作已删除而清空图标格。
- **应用内更新检查**：修复日期版本与正式版本混用时的版本比较错误。

## 下载与校验

- `CrabDesk-Setup-x64.exe`：推荐入口，内嵌 CrabDesk 应用本体，并自动检测、仅下载缺失的 Microsoft 运行组件。
- `CrabDesk-Payload-x64.exe`：应用安装负载，适用于已安装所需运行依赖的环境，不负责补装依赖。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

**重要：本版本的安装包未配置 Authenticode 代码签名。** 应用内更新链的完整性依赖 HTTPS 下载 + `SHA256SUMS.txt` 摘要校验，签名仅作提示、不拦截启动。下载后请务必核对 `SHA256SUMS.txt` 中的 SHA-256 值。

## 数据与升级

CrabDesk 配置保存在 `%LocalAppData%\CrabDesk`。安装或升级不会移动桌面文件，卸载默认保留布局配置和备份。建议升级前在“布局备份”页面创建一次手动备份。

退出或异常终止时，CrabDesk 与 IconGuard 会恢复接管前的 Explorer 图标显示状态和已记录的位置。

## 已知限制

- 仅支持 Windows 10/11 x64，不支持 Windows 7/8、ARM64 或虚拟桌面独立布局。
- 不包含云同步、多标签组合盒子或真实文件夹整理规则。
- 本轮发布未提供 Authenticode 代码签名；如组织策略要求受信任签名，请等待带签名的后续版本。
- 自动化测试与单机桌面验收已完成；Windows 10/11 真实多屏混合 DPI、显示器插拔与睡眠唤醒的组合验收尚未覆盖全部硬件环境。
- 已验证 Wallpaper Engine；其他动态壁纸软件、特殊 Explorer 修改工具和非标准桌面外壳仍需按兼容性清单逐项验证。
