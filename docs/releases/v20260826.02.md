# CrabDesk 20260826.02

2026 年 8 月 26 日测试版，对比上一版本 `v20260826.01`。本次更新推出全新的自研图形化安装器，统一应用安装、依赖检测与在线更新的分发链路，同时优化启动时接管桌面的流畅度。

## 全新自研图形化安装器

- 重新设计 `CrabDesk-Setup-x64.exe`：从简单的在线引导程序升级为完整的 CrabDesk 原生安装向导，统一承载首次安装、覆盖升级、依赖修复和应用启动。
- 安装界面使用 Native AOT、Win32 与 GDI 自主实现，无需目标电脑预先安装 .NET；支持系统深浅色主题、高 DPI 缩放、圆角窗口、Lucide 图标及平滑进度动画。
- 首页会逐项显示运行环境检测结果，并区分“已就绪”“检测中”和“需自动下载”；检测结束前不会误触发安装。
- 支持识别现有安装及版本，自动进入覆盖升级模式并沿用原安装目录；升级前会关闭正在运行的 CrabDesk，用户的桌面分区和配置保持不变。
- 支持直接编辑或浏览选择安装目录，实时显示所需空间和目标磁盘剩余空间，并可选择是否创建桌面快捷方式。
- 安装过程中显示当前步骤、整体百分比、已下载容量、总容量和实时下载速度；完成后可直接启动 CrabDesk。
- 新增安装取消确认、失败详情、重试与关闭页面；临时下载和释放目录会在流程结束后自动清理。
- 保留 `/SILENT`、`/VERYSILENT` 等自动化安装能力，并提供只检测平台、内嵌 Payload 和依赖状态的诊断模式。

## 运行环境智能检测与安全下载

- 安装器会在开始前验证 Windows x64 平台，最低支持 Windows 10 版本 2004（内部版本 `19041`），不满足要求时直接显示明确提示。
- 安装器会检测并仅安装当前系统缺少的组件：
  - Microsoft .NET 8 Desktop Runtime x64（最低 `8.0.30`）
  - Microsoft Windows App SDK 1.8 Runtime x64（`1.8.260710003`）
  - Microsoft Visual C++ 2015–2022 Redistributable x64（最低 `14.50.35719.0`）
- 依赖安装包固定使用 Microsoft 官方 HTTPS CDN 地址；构建时解析并嵌入版本、下载地址和 SHA-256，不再运行时依赖不确定的第三方来源。
- 每个下载文件在执行前同时验证 SHA-256 完整性和 Microsoft Authenticode 数字签名，并限制重定向协议、重定向次数和最大文件大小。
- 安装依赖时会识别成功、已安装及需重启返回码；静默安装会在无需重启时复查依赖状态，发现异常则中止应用部署并给出明确错误。
- CrabDesk 应用 Payload 直接内嵌在最终 Setup 中，释放后再次校验 SHA-256，避免应用载荷在安装过程中被替换或损坏。

## 单一安装包与更新链路

- 正式发布统一为唯一安装包 `CrabDesk-Setup-x64.exe`；GitHub Release 不再要求用户在不同安装包之间选择。
- CrabDesk 主程序改为 framework-dependent 发布，由 Setup 自动补齐缺失运行环境，从而降低公开安装包体积和重复运行库占用。
- Inno Setup 现在只生成内部应用载荷 `CrabDesk-Payload-x64.exe`，负责按用户安装、快捷方式、覆盖升级及卸载；该 Payload 不作为独立下载资源公开。
- 应用内更新统一查找并下载 `CrabDesk-Setup-x64.exe`，移除不同包类型的资源名分支和旧资源回退逻辑。
- 发布流水线调整为“发布应用 → 签名应用 → 构建并签名 Payload → 嵌入并签名最终 Setup → 生成校验清单”，确保稳定版产物使用同一发布者证书和可信时间戳。
- GitHub Release 最终只上传 `CrabDesk-Setup-x64.exe` 与 `SHA256SUMS.txt`，并继续在应用内下载更新后校验安装包哈希。

## 启动接管桌面性能

- 重排启动接管顺序：准备替换窗口期间继续保留 Explorer 原生桌面可见且可交互，所有表面就绪后再集中完成视觉交接。
- 桌面图标和盒子只合成一次最终画面，不再先显示未完成的中间层，也不再在构造完成后重复执行整屏 `SetVisible + Refresh`。
- 在 171 个桌面项目、175% 缩放的当前验证环境中，接管阶段由约 `2.39 秒` 降至 `1.39 秒`，耗时减少约 `42%`，整屏图标渲染由 3 次降至 1 次。
- 保留表面就绪检查、窗口层级验证及失败回滚；接管失败时仍会恢复 Explorer 图标层与桌面输入。
