# CrabDesk 1.2.0

基于 `v1.1.0`（`9b6b649`），新增桌面歌词、控制中心、性能和网络监控，完善跨屏交互并降低持续绘制与常驻内存开销。

## 桌面歌词

- 新增桌面歌词组件，读取 Windows 媒体会话，自动匹配 QQ 音乐、网易云音乐或 LRCLIB 歌词，支持导入 LRC、QRC、YRC 和 TTML 并记住对应歌曲。
- 支持逐字覆盖与逐行高亮、行数和校准设置；句间停顿保留上一句覆盖，直到下一句开始点亮。
- 各层级字号固定，长句按播放进度横向滚动，暂停时保持当前位置。
- 支持选择系统字体、常规/斜体、100–900 字重、文字颜色和透明背景；设置在右键菜单和组件设置页调整并自动保存。
- 播放器图标随媒体来源切换，内置 QQ 音乐、网易云音乐、酷狗、酷我、Spotify 和 Apple Music 图标。

## 控制中心

- 新增控制中心组件，提供音量、静音、亮度、Wi-Fi、蓝牙、夜间模式及媒体播放控制。
- 支持选择亮度目标屏幕、切换音频输出设备、调整独立应用音量，以及麦克风输入设备、音量和静音控制。
- 增加连接详情、显示/投影操作和可自定义的快捷操作，完善按钮的悬停、按下反馈与弹出面板定位。
- 调整音量和亮度时在后台读写设备，合并连续滑块请求，减少输入等待；外接屏幕按所选设备使用 DDC/CI 调节亮度。

## 性能与网络监控

- 新增性能组件，展示 CPU、GPU、内存、磁盘状态、硬件型号及可用的温度读数。
- 新增网络组件，支持完整信息、仅速度和速度曲线三种样式；可选择网卡、设置延迟目标并主动查询公网 IP。
- 固定网速数值与单位的位置，改善较长硬件型号的显示。

## 桌面交互与资源占用

- 便签与待办支持自由调整尺寸和边缘吸附，完善盒子与组件跨屏拖动、混合 DPI 和毛玻璃内容交接。
- 歌词复用局部上传纹理和静态行缓存，合并逐字覆盖绘制，降低持续播放时的 CPU 和逐帧分配。
- 释放空白屏幕的前景画布/纹理，以及点击遮罩上传后的临时缓冲；本机双屏、9 个折叠盒子的同配置采样中，平均工作集从 558.8 降至 497.6 MiB，私有内存从 402.8 降至 348.1 MiB。
- 设置页的组件预览改为静态展示，在调整设置时刷新，减少持续重绘。

## 验证

- Release 配置全量回归：`CrabDesk.Tests` 821 项、`CrabDesk.WinUI.Tests` 1261 项、`CrabDesk.Bootstrapper.Tests` 46 项，合计 **2128 项通过**，无失败或跳过。
- 发布配置与 `build/verify-release-workflow.ps1` 检查通过；构建仍有原有编译警告。
- 歌词逐字覆盖、句间停顿、固定字号与横向滚动、字体/字重、透明背景、混合 DPI 局部绘制和原生鼠标命中均有回归验证。

## 下载与升级

- `CrabDesk-Setup-x64.exe`：推荐安装入口，内嵌应用负载，按需补装缺失的运行依赖。
- `CrabDesk-Payload-x64.exe`：已具备运行依赖时使用的应用安装负载。
- `SHA256SUMS.txt`：两个安装程序的 SHA-256 校验值。

支持 Windows 10 / 11 x64，升级保留已有配置与布局。发布包沿用未配置 Authenticode 签名的策略，完整性通过 HTTPS 与 SHA-256 校验。
