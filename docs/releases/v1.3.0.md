# CrabDesk 1.3.0

基于 `v1.2.0`（`727fa41`），新增组件中心和文件中转站，提供扁平桌面图标与快捷方式箭头开关，并完善组件外观、歌词和网络监控。

## 组件中心

- 新增可选的组件中心，从托盘或快捷键打开，在屏幕右侧集中使用常用组件。
- 支持添加组件、将已有组件移入或移回桌面，保留内容与原桌面位置；拖动卡片上方的把手可排序，顺序自动保存。
- 支持独立的跟随系统、浅色和深色主题；卡片内的编辑、待办、翻译、天气、文件拖放和控制操作保持可用。
- 优化展开、收起和快速反向切换动画，修复面板尚未展开就出现外圈阴影，以及底层窗口圆角露出的问题。

## 桌面图标外观

- 新增 macOS 风格的扁平图标外观，应用与文件夹采用统一底板，文件采用折角纸张样式。
- 适配 PDF、Office 文档、文本、压缩包、图片、音频、视频和代码等文件类型，保留图片缩略图的比例与文件识别信息。
- 支持调整应用底板、文件底板和角标颜色，桌面与盒子使用一致的图标外观。
- 新增快捷方式箭头开关，可独立于扁平外观使用，切换后立即刷新并保存选择。

## 文件中转站

- 新增文件中转站组件，支持批量拖入、点击添加、选择多个文件并拖出到其他应用。
- 提供“引用原文件”和“复制到中转站”两种收集方式；已有条目保留各自的收集方式。
- 支持全局悬浮窗口、贴边自动收起、悬停或拖入展开、图钉保持展开，以及多屏位置恢复。
- 提供打开文件、打开所在位置、复制路径与移除操作，副本清理前显示确认；布局备份保存条目元数据，文件副本需单独迁移。

## 组件外观与布局

- 组件亚克力可跟随盒子，或独立设置背景色、不透明度与模糊强度；实色组件可选择特色、浅色和深色主题。
- 新增独立的组件圆角设置，支持 0–20 DIP，并同步桌面、预览、亚克力裁切与窗口区域。
- 完善组件字体、字号、字重和斜体设置，以及组件详情页的预览与分组布局。
- 桌面歌词支持调整宽高，按可用高度显示上下文歌词，保留固定字号，并提供行间距调整。
- 修正天气图标与右侧摘要的对齐，优化控制中心无媒体播放时的布局，减少底部空白。
- 界面图标统一采用 Tabler Icons，保留天气图形和媒体来源等内容图标的功能配色。

## 网络与控制

- 控制中心增加物理与虚拟网卡管理，可查看状态，并通过 Windows 管理员授权启用或禁用指定网卡。
- 网络监控详细视图增加流量最高的三个进程，支持按下载或上传排序；进程流量采集需要管理员权限。
- 完善活动网卡自动选择与切换，保留指定网卡总网速、延迟和公网 IP 查询。

- 发布配置、`build/verify-release-workflow.ps1` 与 Tabler 图标生成结果检查通过；构建仍有既有编译与本地 SDK 依赖警告。
- 安装包补齐 Tabler Icons 和 TraceEvent 的许可证文件。

## 下载与升级

- `CrabDesk-Setup-x64.exe`：推荐安装入口，内嵌应用负载，按需补装缺失的运行依赖。
- `CrabDesk-Payload-x64.exe`：已具备运行依赖时使用的应用安装负载。
- `SHA256SUMS.txt`：两个安装程序的 SHA-256 校验值。

支持 Windows 10 / 11 x64，升级保留已有配置与布局。发布包沿用未配置 Authenticode 签名的策略，完整性通过 HTTPS 与 SHA-256 校验。
