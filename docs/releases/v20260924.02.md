# CrabDesk 20260924.02

本次更新基于 `v20260924.01`，修复应用内更新检查的版本比较问题；同时包含面向 1.0 正式版的准备性修正。

## 更新检查

### 修复版本比较，正式版不再被日期版本压制

- 修复应用内更新检查中日期格式版本与正式版本混用时的排序错误。
- 此前的比较方式把日期编号当作主版本号，于是 `20260924.01` 被排在 `1.0.0` 之前。结果是：已经安装在日期渠道版本上的用户检查更新时，会被判定为「已是最新版本」，**永远不会收到 1.0.0 的更新提示**。
- 现在日期渠道版本仍按日期先后正确排序（`20260924.01` < `20260924.02`），并整体位于早期 `0.x.y` 版本之上、正式版 `X.Y.Z` 之下。
- 因此本版本是一个过渡版本：**先升级到本版本，应用内更新检查才能正确识别并升级到后续的 1.0 正式版**。直接安装 1.0.0 安装包同样不受影响。
