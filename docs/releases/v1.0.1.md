# CrabDesk 1.0.1

CrabDesk 1.0.1 是面向 Windows 10/11 x64 的稳定维护版本，包含桌面盒子创建、布局编辑和更新体验方面的改进。

## 主要改进

- **新建盒子默认尺寸**：新创建的普通盒子、右键菜单创建的盒子和映射文件夹盒子默认使用 `244 × 288 DIP`，并保留现有盒子的自定义尺寸。
- **管理盒子几何编辑**：设置页“管理盒子”现在显示所选盒子的工作区 DIP 位置与尺寸，可直接编辑 X、Y、宽度和高度；修改会立即应用并沿用工作区边界、动态最小尺寸和持久化逻辑。
- **右键菜单创建位置**：从桌面 Explorer 右键菜单创建盒子时，新盒子会尽量跟随菜单触发位置，并兼容多显示器、负坐标、工作区偏移和 DPI 缩放。
- **悬停展开动画**：图标仍在异步加载时也会使用临时动画缓存，减少动画期间的整盒重绘和掉帧。
- **更新检查缓存**：应用升级后会丢弃由旧版本生成的更新缓存，避免旧的 ETag 或“已是最新”状态遮挡新版本。

## 升级说明

- 本版本保持现有布局数据格式，不会重置已保存盒子的尺寸、位置或内容。
- 安装包会继续检查并补装缺失的 .NET Desktop Runtime、Windows App Runtime 和 Visual C++ 运行库。
- 建议升级前在“布局备份”页面创建一次手动备份。

## 下载与校验

- `CrabDesk-Setup-x64.exe`：推荐入口，包含应用安装负载并自动处理缺失的运行组件。
- `CrabDesk-Payload-x64.exe`：已具备运行依赖时使用的应用安装负载。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。
