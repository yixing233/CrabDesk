# CrabDesk 20260822.01

2026 年 8 月 22 日测试版，对比上一版本 `v20260821.01`（`e4c7bb5`）。本次更新集中优化盒子的滚动与动画性能、重叠盒子的悬停聚焦逻辑、菜单窗口与布局，并完成 CrabDesk 自有界面的 Lucide 图标统一替换。

## 新功能与交互改进

### 盒子悬停聚焦与层级

- 鼠标进入盒子的可见区域后，无需点击即可立即将该盒子判定为当前聚焦盒子，并显示在其它重叠盒子之上。
- 聚焦顺序同时用于绘制和命中测试，重叠区域会优先响应当前聚焦盒子，不再出现画面在上层、点击却落到下层的层级不一致。
- 聚焦层是临时显示层，不会改写用户通过「层级」菜单设置的持久 `StackOrder`，也不会因鼠标移动频繁保存配置。
- 移动或缩放盒子结束时不再隐式修改持久层级；基础层级继续由「置于顶层 / 上移一层 / 下移一层 / 置于底层」命令管理。

### 盒子项目慢速双击重命名

- 盒子内的文件和文件夹现在支持与 Windows 桌面一致的慢速双击重命名：先单击选中，间隔超过系统双击时间后再次单击同一项目即可进入编辑。
- 重命名判定只接受同一项目，并限制在 900 毫秒内，避免普通双击被误识别为重命名。
- 一旦指针开始拖动，待处理的重命名会立即取消，确保拖放操作优先。
- 只读映射盒子继续禁止重命名；普通盒子和可写映射盒子的文件系统项目保持支持。

## 性能与流畅度

### 盒子滚动

- 重新调整滚轮步长：默认三行滚轮设置下，每格约滚动 `0.75` 个项目单元，不再一次跳过多行内容。
- 高精度触控板的小幅滚轮增量按比例保留，细微滚动不再被强制放大成完整行跳转。
- 滚动动画加入独立动态渲染通道，只更新正在滚动的盒子区域，不再在每一帧重绘并上传整个显示器图层。
- 滚动期间暂停项目悬停高亮，动画完成 120 毫秒后按物理指针位置重新对齐，修复高亮停留在已经滚走项目上的问题。
- 每帧只重建项目矩形，不重复计算不变的盒子标题栏、标签栏和外框；滚动结束时再合并稳定画面。
- 滚动后同步清理旧的扩展命中区域，避免文字标签命中范围仍停留在滚动前的位置。

### 分层窗口局部更新

- 新增 `UpdateLayeredWindowIndirect` 脏矩形更新能力，可只复制和提交发生变化的物理像素区域。
- 局部更新复用持久 DIB 与 GDI 资源，减少全屏位图复制、逐行 P/Invoke 和全显示器上传带来的开销。
- 当窗口尚未完成首次全量呈现、脏区域无效或系统调用失败时，会自动回退到原有全量呈现路径，保证兼容性。
- 脏区域会按 DPI 对齐到物理像素并增加抗锯齿安全边界，避免局部刷新留下半透明边缘或裁切圆角。

### 移动、展开与收起动画

- 移动盒子前预生成盒子视觉缓存；拖动过程中主要平移缓存位图，不再逐帧重新绘制标题、图标、文字和背景。
- 展开/收起动画同样复用完整盒子视觉缓存，并通过圆角裁剪展示当前高度，降低每帧绘制成本。
- 高度动画和滚动动画统一走盒子局部更新路径，保持在同一个父分层窗口内，减少不同窗口之间交接造成的闪烁。
- 高度动画不再每帧完整重建全部盒子几何，只更新发生变化的边界、正文区域和缩放手柄；动画结束后再生成稳定几何。
- 动画交互区域在整个过渡期间覆盖起始高度与目标高度的较大值，避免收起/展开过程中出现短暂点击穿透。
- 动画时长按剩余距离缩放：完整展开/收起保持约 220 毫秒，短距离反向切换最低约 80 毫秒，连续悬停切换更跟手。

## 悬停自动展开

- 支持从一个已展开盒子的标题栏直接切换到另一个自动展开盒子；新盒子完成展开延迟后，在同一次状态转换中收起旧盒子并展开新盒子。
- 重叠盒子中，视觉最上层的标题栏可以接管当前展开状态，不再被下方已展开盒子的正文区域阻挡。
- 指针在切换延迟完成前返回原盒子时，会取消待处理切换，避免误收起和来回闪烁。
- 同一次悬停结构变化只更新一次窗口区域并提交一次画面，减少展开、收起连续触发时的重复刷新。

## Lucide 图标统一

### 设置窗口

- 内置并使用 Lucide 字体与 `LucideIcon` 控件，统一替换设置窗口中 CrabDesk 自有的 `SymbolIcon` 与 `FluentIcons.WinUI` 图标。
- 已覆盖主导航、盒子管理、映射文件夹、智能整理、规则编辑、备份与恢复、更新检查、发布页、确认对话框等操作和状态图标。
- 调整了部分语义不准确的映射，例如智能整理使用 `Sparkles`、布局备份使用 `Archive`、映射文件夹使用 `FolderGit2`、恢复使用 `RotateCcw`。
- 移除 `FluentIcons.WinUI` NuGet 依赖，Lucide 字体随应用打包，不依赖系统是否安装对应字体。

### 桌面运行时

- 新增 Runtime 独立的 Lucide 字形服务，使 WinForms、GDI 和 WPF 桌面对话框共享同一套图标语义，而无需让 Runtime 依赖 WinUI 项目。
- 盒子标题栏菜单按钮改用 Lucide `Menu`；展开方式切换按钮改用上下双箭头 `ChevronsUpDown`，与菜单中的显示模式语义保持一致。
- 盒子菜单已覆盖粘贴、重命名、显示模式、子标签、层级、颜色、视图、排序、设置和删除等操作。
- 托盘菜单已覆盖打开 CrabDesk、新建盒子、智能整理、暂停/恢复接管、重新连接、开机启动、主题和退出；动态图标会随暂停状态和开机启动状态切换。
- 保留 Shell 文件图标、CrabDesk 品牌图标及系统/框架自带控件装饰，不替换不属于 CrabDesk 操作语义的图形。

### 警告、错误与确认对话框

- 桌面确认对话框扩展为确认、警告和错误三种模式，分别使用 Lucide `Trash2`、`TriangleAlert` 和 `CircleAlert`。
- 替换 Runtime 中导入、拖放、删除、重命名、颜色设置等路径的系统错误/警告图标，统一浅色与深色主题下的外观。
- 普通消息对话框只显示「确定」按钮并默认聚焦；Enter 确认、Esc 关闭。删除确认仍保留安全的取消优先行为。

## 菜单窗口与视觉布局

### 任务栏与窗口所有权

- 修复盒子主菜单和二级菜单作为独立顶层窗口出现在任务栏的问题。
- 主菜单与所有二级菜单统一使用 `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`，同时移除 `WS_EX_APPWINDOW`，打开菜单不会抢占应用焦点或生成任务栏图标。
- 主菜单绑定到桌面根宿主，二级菜单绑定到父菜单，形成完整的原生所有者链；多级菜单关闭、外部点击检测和动画行为保持一致。

### 尺寸、对齐与间距

- 菜单改为显式的图标、文字和二级箭头三列布局，避免 WinForms 默认图片列、勾选列与高 DPI 缩放相互叠加。
- 图标基准尺寸调整为 `16 DIP`，随 DPI 缩放；文字统一从 `32 DIP` 位置开始，二级箭头使用独立尾部区域，不再与文字或图标重叠。
- 菜单宽度根据最长文字、图标槽、二级箭头槽和外边距动态计算，修复长文本截断以及不同菜单宽度不协调的问题。
- 行高调整为 `30 DIP`，选中背景、圆角、边框和分隔线均按当前 DPI 缩放。
- 主菜单重新按功能分组，补充分隔线，降低连续命令堆叠带来的视觉混乱。
- 顶部和底部外边距统一为 `6 DIP`，左右保持 `4 DIP`；首项与末项不再紧贴圆角边框，主菜单和二级菜单保持对称。

## 修复

- 修复盒子列表较长时滚动帧率低、滚轮步长过大、触控板细微滚动不连续的问题。
- 修复滚动过程中悬停高亮反复出现、位置滞后或停留在错误项目上的问题。
- 修复盒子展开/收起和滚动动画每帧触发全显示器位图上传造成的卡顿。
- 修复移动盒子时重复绘制完整盒子内容导致的帧率下降。
- 修复自动展开盒子快速反向切换时动画时长固定、响应显得拖沓的问题。
- 修复重叠自动展开盒子之间难以直接切换、旧盒子先闪烁收起再展开新盒子的问题。
- 修复盒子二级菜单出现在任务栏、菜单窗口抢焦点的问题。
- 修复菜单图标含义不准确、尺寸偏小、图标/文字/箭头间距不均和首尾留白不足的问题。
- 修复部分映射盒子视图在当前标签没有可见项目时，空状态判断仍受其它标签项目影响的问题。
- 修复盒子内项目缺少与桌面一致的慢速双击重命名入口。

## 内部改进

- 分离持久盒子层级与临时聚焦层级，避免悬停置顶污染用户配置。
- 抽取慢速双击重命名策略，桌面图标与盒子项目共享相同的时间窗口判定。
- 新增移动盒子缓存、盒子高度动画缓存及统一释放逻辑，工作区刷新、图标缓存刷新和窗口销毁时都会回收位图资源。
- 新增局部盒子动画绘制策略、物理像素脏区域计算、滚动悬停抑制和动画几何更新策略测试。
- 新增 Runtime 与 WinUI Lucide 字形契约测试，确保所有实际使用的图标都能解析到有效字形。
- 新增菜单非激活工具窗口样式、二级菜单类型、DPI 图标尺寸、列间不重叠及首尾对称留白测试。
- 增加盒子静态图层、桌面图标图层和悬停聚焦切换的诊断日志，便于排查特定 DPI 与桌面宿主环境的问题。

## 兼容性

- 本次更新不修改配置 Schema，现有盒子、分组、层级、备份和显示设置无需迁移。
- 持久 `StackOrder` 的含义保持不变；悬停聚焦只影响当前运行时的视觉与命中顺序。
- 局部分层更新具备全量呈现回退路径，不支持或初始化未完成的环境仍可使用原有渲染方式。
- Lucide 字体作为应用资源打包；系统 Shell 文件图标和 CrabDesk 品牌资源保持原样。
