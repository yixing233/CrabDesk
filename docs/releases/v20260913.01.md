# CrabDesk 20260913.01

本版本对比线上最新版本 `v20260911.02`，重点改进桌面盒子外观设置、图标缩放、跨屏拖拽体验，并修复 Windows App Runtime 依赖检测不准确导致的安装后启动失败问题。

## 桌面盒子外观设置

- 将盒子外观设置重构为分组卡片式页面。
- 使用独立的二级导航切换盒子表面、标题栏、图标与标签、桌面图标名称。
- 统一卡片宽度、居中布局和设置项对齐方式，移除卡片内部多余分割线。
- 优化颜色选择器、选中高亮颜色文案和字体选择体验。
- 统一开关尺寸并隐藏冗余的开/关文字。

## 图标缩放与布局

- 修正图标缩放时空白区域被同比放大的问题，保留文字和内边距的合理比例。
- 限制稀疏网格单元格的额外宽度，避免大图标下出现过宽的选择区域。
- 修正极小滚动轨道上的缩略块高度计算。

## 拖拽与多显示器

- 新增多选桌面图标跨显示器拖拽布局算法。
- 跨屏操作时保留其他显示器的图标布局；目标显示器空间不足时使用紧凑排列，并保证操作原子性。
- 新增独立的透明、免激活顶层拖拽预览层，跨 DPI 和负坐标显示器时保持抓取点稳定。
- 统一盒子、桌面、资源管理器和无目标区域的拖拽预览，避免重复幽灵图像。
- 混合系统图标与文件图标时不再暴露不完整的文件拖放列表。
- 拖拽经过手动标签时自动选中对应标签，并显示当前标签标题。

## 安装器与依赖修复

- 使用 Windows App Runtime 实际 MSIX 版本 `8000.921.1539.0` 进行版本检测，不再误用 NuGet 包版本 `1.8.260710003`。
- 检测 Windows App Runtime 的 Framework、Main、Singleton 三个必需组件，减少安装完成后启动时报 `Required components missing` 的情况。
- 增强安装构建脚本的依赖版本格式校验。
