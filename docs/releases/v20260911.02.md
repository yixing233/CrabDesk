# CrabDesk 20260911.02

2026 年 9 月 11 日下午版本，对比版本 `v20260911.01`。本次更新重点接入了酷呆桌面（Coodesker）1:1 原生无损导入能力，彻底剔除所有多余的推测与关键字规则，打通底层密码学解密流水线，原样还原盒子的真实位置、多子标签结构及图标收纳；重构了文件拖拽在同卷与跨磁盘卷下的移动/复制语义，杜绝误剪切风险；移除了接管桌面右键菜单的功能，恢复 Windows 原生桌面右键菜单；并在 CI/Release 构建流中增加了防死锁诊断机制。

## 酷呆桌面（Coodesker）1:1 原生无损覆盖迁移

- 打通底层原生解密引擎：逆向接入酷呆密码学解密例程，直接将本机 `%AppData%\Coodesker\cache\desk.cache` 与 `.backup` 备份数据还原为无损的原始层级结构，彻底杜绝猜测。
- 彻底剔除多余关键字规则与生造盒子：完全移除了按文件名称盲猜分类的逻辑，严格做到酷呆记录中有什么就导入什么；移除了生造的临时盒子，游戏项目 1:1 归入原生的 `0` 盒子中。
- 多子标签（Sub-Tabs）原生映射：完整识别多标签盒子的子标签结构（如 `目录`、`压缩`、`其它` 等标签），通过 `ItemTabAssignments` 实现标签与图标的双向精准过滤。
- 桌面自由图标零打扰保护：位于酷呆桌面原生根视图的常用软件图标保持未分配状态，完好停留在桌面自由空间。
- 布局备份页面专属卡片：在设置中心备份页面首位加入醒目的「从酷呆桌面迁移」卡片，支持一键从本机迁移与选择 `.backup` 文件导入，覆盖前自动创建安全备份。

## 文件拖拽传输策略重构（移动 vs 复制）

- 智能同卷/跨卷判定：同磁盘卷（如 C 盘到 C 盘桌面）默认执行移动；跨卷/外接驱动器（如 D 盘、U 盘到 C 盘桌面）默认执行复制（光标带 `+` 号），彻底杜绝从 U 盘拉取文件时意外剪切删除源文件的风险。
- 修饰键最高优先级统揽：按住 `Ctrl` 强制复制，按住 `Shift` 强制移动。
- 消除桌面图标收纳误导提示：桌面自由图标拖入普通盒子为虚拟归属调整，光标由原先带加号的复制改为标准的移动，与心智模型保持一致。
- 视觉与落盘完全对称：彻底统一光标效果与释放端的实际文件系统操作。

## 移除桌面右键菜单接管

- 恢复 Windows 原生桌面右键菜单：桌面空白处右键直接由 Windows Shell 处理，即时唤起原汁原味的原生菜单。
- 清理 Explorer 注册表项：移除并注销向 `DesktopBackground\Shell\CrabDesk` 写入的注册表菜单项，保持系统菜单清爽干净。
