# CrabDesk 20260826.01

2026 年 8 月 26 日测试版，对比上一正式版本 `v20260824.02`。本次更新重点完善桌面与盒子的统一交互、拖拽与文件移动性能、备份预览和 AI 整理工作台，并调整桌面右键菜单与后台运行方式。

## 桌面与盒子：统一选择、重命名和删除

- 桌面与盒子共享同一组选中状态；在桌面或盒子中继续多选时，不再清空另一处已经选中的项目。
- 统一单击、框选、右键和组合键的选择规则，桌面与盒子可共同执行复制、剪切、删除等操作。
- 盒子内文件进入重命名后，鼠标移出盒子不会让盒子自动收起；点击图标外部会结束重命名，点击盒子外部还会同步关闭悬停展开的盒子。
- Delete 删除前新增确认对话框：单个项目显示名称，多个项目显示数量；删除内容进入回收站，只读或系统项目会明确提示并跳过。
- 取消删除后会完整恢复键盘命令状态，原选中项目可以再次使用 Delete、复制、剪切等快捷键。
- 修复确认对话框首次出现时先闪过大尺寸窗口的问题，并为较长提示内容增加滚动承载区域。

## 拖拽、文件夹与局部刷新

- 重写桌面图标、盒子图标和盒子窗口的拖拽反馈，拖动过程跟随真实鼠标位置，不再只在松手后瞬移。
- 图标位置提交改为局部快照和脏区域刷新；桌面重排、拖入盒子、从盒子释放及取消拖拽不再清空全部图标缓存或重绘整个桌面。
- 优化盒子与桌面之间的文件移动，减少文件系统监听器与主动刷新重复执行造成的卡顿和假死。
- 从资源管理器拖入桌面时按鼠标落点放置；多文件保持拖放顺序，已有图标和被挤开的图标只刷新受影响区域。
- 从桌面拖到资源管理器后，根据系统 OLE 移动结果局部移除图标；针对父目录、目标文件夹等监听通知增加事务抑制，避免再次触发全局刷新。
- 从系统 Desktop 文件夹把已经位于桌面的项目拖回桌面时，仅更新图标位置，不再复制出带 `(2)` 后缀的重复文件。
- 桌面文件现在可以直接拖入桌面上的真实文件夹，并遵循资源管理器的复制/移动修饰键语义；会拒绝拖入自身、把父文件夹拖入其子目录等无效操作。
- 移除残留的图标位置预览通道，拖拽高亮只覆盖实际目标图标或盒子区域。

## 盒子动画与图标呈现

- 展开、收起和移动盒子改用局部合成帧，缩小每帧重绘范围并复用稳定背景，降低动画拖沓和桌面闪烁。
- 展开前按需预热真实图标，动画期间复用图标与盒子缓存，减少首次展开时占位图标闪现和二次加载。
- 动画时长会根据移动距离调整；盒子底边变化、拖拽浮层和标题栏操作按钮分别更新，避免整块窗口重复合成。
- 修复盒子拖动结束后标题栏图标消失、悬停操作按钮丢失，以及拖出盒子后再拖回触发错误导入提示的问题。
- 优化盒子滚轮滚动的步进与悬停处理，滚动或动画期间不再残留旧图标高亮。

## 备份列表与内置预览

- 重新整理备份卡片布局，移除“真实桌面快照”和内部结构版本标记等面向实现的字段。
- 支持双击备份直接预览，也可以通过工具栏的“预览”命令打开。
- 新增应用内全尺寸图片查看器：预览区域占满窗口，缩放、适应窗口和关闭按钮以悬浮工具栏呈现。
- 支持以鼠标所在位置为中心的滚轮缩放、拖拽平移、双击切换适应比例，并阻止滚轮继续带动页面滚动。
- 修复预览标题区无法拖动窗口、拖动抖动、关闭图标裁切及工具栏图标悬停变黑等问题。

## AI 整理工作台

- AI 整理迁移到独立工作台窗口，集中展示待处理桌面项目、分类标签、连接设置、运行进度与结果预览。
- 支持选择具体项目参与分类，使用可编辑标签片管理分类范围，并为文件和文件夹显示真实图标。
- 新增流式思考过程与结构化输出展示，并对界面刷新进行节流，避免模型持续输出时阻塞窗口。
- 显示总耗时、首字耗时、输入/输出/总 Token 等运行指标，便于检查模型响应与使用量。
- 支持可选的 Tavily 网络检索、批次分类和安全的本地兜底规划；连接测试和应用结果仍保持显式确认。
- 分类结果新增按类别分组的看板视图和待确认分组，也可切换到原始 JSON 视图。
- 思考过程与 JSON 结果均可一键复制到剪贴板，并提供复制成功提示。

## 桌面右键菜单与后台运行

- CrabDesk 桌面右键菜单移动到菜单顶部，并新增“重新连接桌面”和“退出 CrabDesk”命令。
- 菜单命令支持单实例进程间转发；`--reconnect` 会重新连接桌面宿主并刷新显示器与图标，`--exit` 会退出正在运行的实例。
- 右键菜单图标改用 Lucide 字体生成，并写入 16、24、32、48 像素多尺寸 ICO；注册变化后主动通知资源管理器刷新菜单缓存。
- 移除系统托盘图标及托盘菜单；关闭设置窗口统一隐藏窗口并保持桌面服务运行，退出操作改由桌面右键菜单明确触发。
- 系统从睡眠恢复后复用“重新连接桌面”流程，重新绑定桌面宿主并恢复桌面表面。
