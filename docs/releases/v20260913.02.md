# CrabDesk 20260913.02

本版本对比线上最新版本 `v20260913.01`，完整修复安装后提示缺少 Windows App Runtime 的检测误报（#1），并改进安装器的下载速度显示与日志。

## Windows App Runtime 检测完整修复（#1）

- 新增 `WindowsAppRuntimeDetector`：以结构化包查询替代 PowerShell `Get-AppxPackage` 检测，完整校验 Framework、Main、Singleton 与 DDLM 四类 x64 组件。
- DDLM 组件改为「最低版本兼容」判定而非精确匹配：framework/Main 包被系统服务更新到高于 DDLM 基线的版本（如 `8000.946` 配 `8000.921`）时不再误报缺少依赖。
- Windows App Runtime 安装不再请求提权，并在静默安装参数中加入 `--force`。

## 安装器下载体验

- 新增 `DownloadSpeedEstimator`：2 秒滑动窗口 + 指数平滑计算下载速度，替代瞬时差值导致的显示抖动；下载完成时保留最终速度。
- 新增 `InstallerLogger` 结构化日志（敏感字段脱敏、日志注入清洗），记录下载尝试、重试与失败原因。
