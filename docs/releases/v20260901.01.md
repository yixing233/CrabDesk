# CrabDesk 20260901.01

2026 年 9 月 1 日测试版，重点完善安装器依赖处理、桌面与盒子图标交互，以及强调色和菜单体验。

## 安装器与依赖

- 优化安装器首页依赖检测，分别校验 .NET 8 Desktop Runtime、Windows App SDK Runtime 与 Visual C++ Redistributable 的架构和最低版本，避免仅检测到组件名称却无法启动应用。
- Windows App SDK 运行时检测改为按已安装包版本排序并比较最低版本；.NET Desktop Runtime 必须同时满足 `Microsoft.NETCore.App` 与 `Microsoft.WindowsDesktop.App`。
- 依赖下载增加临时文件、失败清理、可取消重试和瞬时网络错误处理，下载完成后再替换目标文件，避免残缺文件被执行。
- 保留 HTTPS、文件大小限制、SHA-256 和 Authenticode 校验；依赖安装返回码会在安装器中明确反馈，异常时不会继续部署应用。
- 安装器与应用版本继续使用 `YYYYMMDD.NN` 日期修订格式，本版标识为 `20260901.01`。

## 桌面与盒子交互

- 盒子采用鼠标悬停临时聚焦到最前层，不修改持久层级设置；离开后恢复原有层级关系。
- 优化桌面与盒子图标拖拽跟随影像，统一鼠标下图标、标签和多选数量角标的尺寸与位置，并支持拖拽桌面图标进入盒子时滚轮滚动内容。
- 修复拖拽、滚动、展开/收起及设置变更引起的整屏刷新，改为更新受影响的局部区域，减少闪烁和卡顿。
- 图片文件缩略图按原始宽高比缩放到图标区域，不再强制压缩为 1:1；桌面和盒子沿用同一图标布局逻辑。
- 悬停和选中状态使用自适应圆角与统一反馈，强调色仅用于交互状态，不再给标题栏及文件图标染色；Lucide 图标保持白色或黑色对比度。

## 菜单与标签

- 盒子标题栏、菜单和子标签标题的图标统一使用 Lucide 图标，并修复点击盒子内容后标题栏操作图标消失的问题。
- 粘贴命令在不可用时以灰色显示并保持一致的悬停区域；菜单项目左右内边距、分组间距和高 DPI 度量统一。
- 子标签标题支持独立的右键菜单；移除无实际作用的层级菜单及置顶/置底等持久操作。
- 新建子标签对话框调整为紧凑、可拖拽的原生窗口，移除多余的“标签名称”标签和占位区域，修复输入框不可见及内容显示不完整问题。

## 稳定性

- 修复退出 CrabDesk 的部分路径未恢复 Explorer 桌面接管状态、导致桌面图标暂时消失的问题。
- 优化启动接管失败和崩溃回退流程，确保原版桌面在应用退出后能够恢复。

## 验证

- 本版本包含安装器、桌面渲染、拖拽、菜单和启动接管相关回归测试。
- 发布产物：`CrabDesk-Setup-x64.exe` 与 `SHA256SUMS.txt`。
