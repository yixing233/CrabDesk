# CrabDesk 1.3.1

发布日期：2026-11-26。对比基准：`v1.3.0` / `9f7ca68`。

## 盒子交互与滚动

- 合并连续的图标悬停刷新，复用展开动画与滚动布局缓存，减少鼠标经过图标、展开盒子时的重复绘制。
- 连续滚轮输入累积滚动距离，反向滚动及时响应，改善滚动费劲、频繁重新起步的感觉。
- 子标签切换增加轻微横向移动、淡入淡出和指示线过渡；快速连续切换从当前画面衔接，拖放和关闭动画时保持即时切换。

## 文字与图标

- 盒子标题、子标签和文件名统一采用适合透明背景的灰度抗锯齿，按显示器 DPI 生成文字并对齐实际像素，改善彩边和生硬边缘。
- 缓存文字绘制结果，兼顾滚动流畅度；保留字体、字号、长文件名展开与重命名编辑行为。
- 修复部分快捷方式图标异常缩小、只在图标区域一角显示的问题。
- 图标外观增加扁平与渐变风格选择，完善应用、文件夹和文件底板的显示。

## 组件体验

- 优化组件中心的拖动排序、卡片间距与编辑区域裁剪，改善便签、待办等内容的编辑体验。
- 完善组件预览、控制中心弹出面板、网络监控文字和待办日期窗口的显示与布局。

## 验证

- Release 配置分批回归：核心 1159 项、桌面界面 1858 项、安装器 46 项，合计 **3063 项通过**。
- 桌面测试串行运行；前台层级、UI Automation 和屏幕取色相关用例在独立测试进程中复核通过。
- 两个实际显示器亮度用例因本机 WMI 查询阻塞未完成，不计入通过数量。
- 发布配置与发布流程检查通过；修正源码检查测试对 CRLF 换行的兼容性。构建仍有既有编译与本地 SDK 依赖警告。

## 下载与升级

- `CrabDesk-Setup-x64.exe`：推荐安装入口，内嵌应用负载，按需补装缺失的运行依赖。
- `CrabDesk-Payload-x64.exe`：已具备运行依赖时使用的应用安装负载。
- `SHA256SUMS.txt`：两个安装程序的 SHA-256 校验值。

支持 Windows 10 / 11 x64，升级保留已有配置与布局。沿用未配置 Authenticode 签名的发布策略，通过 HTTPS 与 SHA-256 校验安装包完整性。
