# CrabDesk 1.1.0

基于 `v1.0.2`（`74f8d5c`），新增六种桌面小组件，完善桌面层级、图标样式与智能整理。

## 桌面小组件

- 新增时钟、月历、便签、待办、翻译、天气，沿用桌面盒子的圆角、配色和毛玻璃材质。支持拖动、跨屏放置、锁定位置和尺寸切换，布局与内容自动保存。
- 使用预览卡片添加和管理组件，显示已有实例并防止重复添加；点击管理卡片打开侧边设置，桌面内容直接在组件中操作。
- 时钟采用黑白指针表盘，提供 180 × 180 DIP 方卡和 288 × 120 DIP 横卡，支持秒针；横卡附数字时间和日期。
- 月历增加“今”按钮；悬停日期显示鼠标附近的农历、节日和节气卡片，宽卡右侧显示近期节日和节气倒数日。
- 便签支持卡片内多行编辑与自动保存。待办支持顶栏添加、条目悬停编辑、完成分组、可选开始/截止日期，以及显示条目摘要的删除确认气泡。
- 翻译支持卡片内输入、Ctrl+Enter 提交、目标语言切换、取消、清空和复制；可独立配置接口、模型、提示词、会话复用和空闲后自动新建会话的时间。
- 天气接入小米天气，支持 Windows 定位、保存多个城市和直接切换；提供天气图标、实况指标、逐小时气温/AQI、七天趋势、可展开预警和生活指数。位置管理与详情独立打开，并增加展开动画。

## 桌面与交互修复

- 修复桌面接管失败后必须重启软件才能恢复的问题，支持在同一进程内重试和重建桌面显示。
- 修复截图工具退出或组件二级菜单展开时，桌面盒子突然覆盖普通窗口的问题；展开后的盒子显示在组件上方。
- 优化 Win+D、任务栏“显示桌面”以及退出文本编辑时的窗口层级恢复，减少盒子和组件隐藏、闪烁的情况。
- 优化盒子和组件的拖动对齐，支持与相距较远的卡片对齐。
- 统一桌面和盒子网格图标的悬停、选中高亮范围、留白和圆角；列表视图保留整行反馈。
- 统一便签、待办和翻译在浏览与编辑状态下的文字位置、行距和圆角，移除额外聚焦高亮边框，修复点击翻译文本末尾时光标位置不正确的问题。
- 调整翻译文字、图标按钮和半透明操作按钮的对比度，改善深浅色卡片的可读性。

## 智能整理

- 自动整理和 AI 分类可识别已有盒子及其子标签，优先复用匹配目标，避免重复创建盒子。
- 区分用户显式指定的目标和自动匹配目标，完善规则编辑、目标状态提示与撤销恢复。

## 下载与升级

- `CrabDesk-Setup-x64.exe`：推荐安装入口，内嵌应用负载，按需补装缺失的运行依赖。
- `CrabDesk-Payload-x64.exe`：已具备运行依赖时使用的应用安装负载。
- `SHA256SUMS.txt`：两个安装程序的 SHA-256 校验值。

支持 Windows 10 / 11 x64，升级保留已有配置与布局。发布包沿用未配置 Authenticode 签名的策略，完整性通过 HTTPS 与 SHA-256 校验。
