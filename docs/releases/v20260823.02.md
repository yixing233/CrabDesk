# CrabDesk 20260823.02

2026 年 8 月 23 日测试版。此版本包含原计划在 `v20260823.01` 发布的标题栏、菜单与性能改进，并修复了发布环境中菜单测试辅助函数缺失导致的编译失败。

## 标题栏与搜索

- 标题栏搜索、展开方式和菜单图标仅在鼠标位于盒子可见区域时显示；拖动盒子时不会闪烁或消失。
- 新增标题栏内搜索框，可实时筛选当前盒子的项目；搜索框继承盒子的字体、配色与强调色。
- 标题以整个盒子为基准确实居中，搜索按钮置于左侧，展开和菜单按钮均匀位于右侧。
- Lucide 图标按物理像素对齐，并在标题栏悬浮层使用高质量抗锯齿，改善 125% 与 150% DPI 下的边缘与笔画一致性。

## 菜单与交互

- 优化盒子主菜单和二级菜单的分组、图标语义、列对齐、长文本宽度及首尾留白。
- 主菜单和二级菜单均不再显示为任务栏窗口，也不会抢占焦点。
- 鼠标移入已打开菜单后，盒子保持展开，不会因指针离开盒子原始范围而关闭。
- 移除盒子静态颜色条；「强调色」仅用于搜索、标签页、拖放、排序和按钮激活态等交互反馈。

## 性能与稳定性

- 滚动、展开/收起、悬停、拖拽与搜索筛选改为局部脏矩形更新，减少整屏图层上传与闪烁。
- 盒子与桌面图标拖拽结束时保留图标缓存，只刷新受影响区域，避免整个桌面图标看似重新加载。
- Shell 状态轮询与图标加载移出 UI 热路径；高频诊断日志改为异步批量写入。
- 二级菜单与 Lucide 字体改为按需配置，降低打开菜单时的同步开销。
- 补齐菜单层级配置的内部契约，并在清理后的 Release 构建中验证，防止增量编译缓存掩盖该类错误。

## 验证

- `CrabDesk.Tests`：222 项通过。
- `CrabDesk.WinUI.Tests`：181 项通过。
- Release 解决方案构建成功，0 个错误；仍有 21 个既有 `MVVMTK0045` WinRT AOT 兼容性警告。
