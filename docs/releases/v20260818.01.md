# CrabDesk 20260818.01

2026 年 8 月 18 日测试版，基于 v20260815.02 之后的 12 个提交。重点：盒子与真实文件夹之间的拖放导入（默认移动语义）、设置窗口高 DPI/最小尺寸修复、桌面图标稳定性（缩略图、临时文件过滤、编辑后归属保留），以及隐藏文件显示设置和两处架构重构。

## 新功能

### 盒子内文件夹拖放导入

- 支持把桌面文件/文件夹**直接拖入盒子中显示的文件夹图标**：映射盒子的真实子文件夹、普通盒子内的桌面文件夹，统一识别为真实文件夹目标。
- 桌面图标拖拽与外部文件拖拽走同一条导入路径，落到目标文件夹而非盒子网格。
- 新增 CrabDeskRuntime.ImportFilesIntoFolderAsync / ImportFilesToMappedFolderSubfolderAsync，导入后自动刷新桌面项与映射快照。

### 拖放默认移动

- 拖到盒子内文件夹图标：**默认移动**，按住 Ctrl 改为复制。
- 从文件夹拖入桌面、盒子根目录、盒子文件夹：**默认移动**，按住 Ctrl 改为复制，与 Windows Explorer 行为一致。
- 拖到普通盒子空白处仍是虚拟分组（文件不动）；只读映射盒子继续拒绝写入。

### 隐藏文件显示设置

- 常规设置新增「显示隐藏文件与 Office 临时文件」开关，默认关闭，与 Windows Explorer 的桌面显示保持一致。
- 开启后可显示 `~$` Office 临时锁文件，以及带有隐藏或系统属性的文件；`desktop.ini` 仍始终隐藏。
- 切换开关后立即刷新桌面项目，并持久化设置，重启应用后保持选择。

## 修复

### 设置窗口（MainWindow）

- 高 DPI 显示器（如 125%/150%/175%）下窗口不再以小于最小尺寸（760×520 DIP）打开：初始尺寸按窗口 DPI 缩放，打开时强制执行最小尺寸。
- 拖拽调整到最小尺寸时不再抽搐：改用 WM_GETMINMAXINFO 在系统层面限制最小跟踪尺寸（跨显示器自动跟随 DPI）。
- 主题验证截图路径同样按 DPI 缩放，截图内容不再被裁切。

### 桌面图标与文件

- **图片文件显示内容缩略图**，不再只显示通用 Shell 类型图标（jpg/png/gif/bmp/webp/ico/tiff/heic 等）。
- 替代桌面默认过滤 Office 临时锁定文件（~$文件）以及 Explorer 隐藏/系统文件，与原生桌面显示一致；可在常规设置中开启显示。
- 文件通过「临时文件替换」方式保存（Office/WPS 常见）后，按路径迁移盒子归属——编辑保存的文件**不会意外回到普通桌面**。

### 拖放预览

- 移除盒子投放过程中的网格插入/补位（挤位）预览，避免与实际落点不一致的虚假排列。
- 映射盒子不再显示不适用的网格重排投影；可投放的子文件夹保留清晰的高亮反馈。
- 拖放排序仍在放下时按鼠标位置实时计算，排列结果不变。

## 重构

- **悬停/选中视觉样式单一来源**：新增 DesktopItemVisualStyle，桌面图标与盒子图标共享选中填充、悬停填充/描边透明度、提亮幅度、按图标大小自适应的圆角，消除两份重复常量。
- **DesktopBoxForm 拆分**：6268 行巨型类按职责拆分为 9 个 partial 文件（核心 / Rendering / Geometry / Icons / RenderPipeline / Input / DragDrop / ContextMenus / TitleEditor），行为不变，227 个成员逐一校验。

## 内部与排查中
