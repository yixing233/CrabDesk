# CrabDesk 1.0.2

本次维护更新基于 `v1.0.1`（`e9f7591`），完善盒子子标签与文件拖拽，并修复桌面菜单、系统图标和备份预览问题。

## 拖拽与子标签

- 支持将一个或多个文件拖到其它子标签；拖动文件时悬停标签可切换内容，放入目标标签内容区即可完成归类。
- 支持拖动子标签调整顺序，提供插入位置提示并保存排序；“全部”标签固定在首位，按 Esc 可取消拖动。
- 完善桌面和盒子中的文件拖向回收站、文件管理器及其它软件的交互，移动后及时刷新来源；取消或目标拒绝接收时保留原分组。
- 修复“此电脑”“回收站”等系统图标无法拖动调整桌面位置的问题。

## 桌面与图标

- 修复选中桌面图标后按 Delete 无法删除的问题。
- 修复清空回收站后空 / 满图标不更新的问题。
- 修复“此电脑”偶尔显示为普通文件夹图标的问题。
- 修复桌面空白处右键误弹出 CrabDesk 可执行文件菜单的问题，并保持 CrabDesk 菜单注册在应用重启后有效。
- 修复 Windows 11 默认桌面右键菜单的“刷新”未触发图标重新排序的问题；CrabDesk 菜单入口位于“显示更多选项”内。
- 统一图标悬停与选中状态的圆角，在外观设置的“图标与标签”中调整“图标高亮圆角”。

## 备份与盒子管理

- 修复备份快照看不到盒子的问题，新快照包含盒子画面，旧快照兼容显示保存的盒子布局。
- 管理盒子页面的列表可随窗口伸展，详情支持滚动。
- 支持删除最后一个普通盒子，盒内文件回到桌面。

## 验证

- Release 配置全量测试：`CrabDesk.Tests` 483 项、`CrabDesk.WinUI.Tests` 726 项、`CrabDesk.Bootstrapper.Tests` 46 项，合计 **1255 项通过**。
- `build/verify-release-workflow.ps1` 发布策略检查通过。

已实机验证 Windows 11 默认菜单刷新、系统图标显示及子标签拖动排序；其它软件接收文件的情况尚未逐一实测。

## 下载与升级

- `CrabDesk-Setup-x64.exe`：推荐安装入口，内嵌应用负载，按需补装缺失的运行依赖。
- `CrabDesk-Payload-x64.exe`：已具备运行依赖时使用的应用安装负载。
- `SHA256SUMS.txt`：两个安装程序的 SHA-256 校验值。

支持 Windows 10 / 11 x64，升级保留已有配置与布局。发布包沿用当前未配置 Authenticode 签名的策略，完整性通过 HTTPS 与 SHA-256 校验。
