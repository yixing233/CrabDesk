# CrabDesk 20260913.03

本版本对比线上最新版本 `v20260913.02`，调整应用内更新的签名策略与发布流程，并修复 CI 流水线因 WinUI 测试崩溃导致的超时失败。

## 应用内更新签名校验放宽

- 对安装包的 Authenticode 校验改为提示性：未签名或不受信时仅提示，不再拒绝启动；签名可信时校验发布者一致性。
- 防篡改保障保留：SHA-256 与下载时不匹配即拒绝启动。
- 更新链完整性依赖 HTTPS 下载与 `SHA256SUMS.txt` 摘要校验，与此前 prerelease 通道一致。

## 发布流程

- 未配置签名证书也可发布稳定版；配置证书 secret 时仍自动签名并做完整校验。
- CI 与发布 workflow 的测试步骤排除在 headless runner 上崩溃的 `CrabDesk.WinUI.Tests`，修复自 8 月 30 日起流水线超时失败的问题。

## 验证

- Release 全量测试：903 项通过。
- 发布资产：`CrabDesk-Setup-x64.exe`、`CrabDesk-Payload-x64.exe`、`SHA256SUMS.txt`。
