# CrabDesk 20260823.01

2026 年 8 月 23 日测试版，对比上一版本 `v20260822.02`。本次更新围绕桌面盒子的标题栏交互、菜单体验与运行时流畅度展开，重点减少悬停、拖拽、滚动和打开菜单时的视觉闪烁与全屏重绘。

## 标题栏与搜索

- 盒子标题栏的搜索、展开方式和菜单按钮改为仅在鼠标位于盒子可见区域内时显示；拖动盒子时不会因短暂的命中变化而消失或闪烁。
- 新增标题栏搜索按钮：点击后在标题栏内展开搜索框，可即时筛选当前盒子的项目；关闭搜索会恢复原有项目视图。
- 搜索框沿用盒子的标题字体、前景色、背景色和强调色，修复此前字体风格不协调、输入时偶发异常的问题。
- 重新平衡标题栏布局：标题以整个盒子为基准确实居中，搜索按钮置于左侧，展开与菜单按钮均匀分布在右侧，避免标题受按钮数量影响而产生视觉偏移。
- 标题栏 Lucide 图标按实际物理像素对齐后绘制，并在独立悬浮层使用高质量抗锯齿。修复 125% 与 150% 等非整数 DPI 下图标边缘粗糙、笔画不均的问题，同时保留悬停时的轻量更新路径。

## 盒子菜单与外观

- 重新整理盒子主菜单和二级菜单的分组、图标、文字列、箭头列及首尾留白；长文本不再拥挤或被不必要地截断。
- 菜单及其二级菜单均作为非激活工具窗口打开，不再显示在任务栏，也不会抢占当前应用焦点。
- 鼠标从盒子进入已打开菜单后，盒子会保持展开；即使菜单区域超出原盒子范围，也不会被错误收起。
- 完成运行时菜单的 Lucide 图标替换，并修正粘贴、重命名、显示模式、子标签、层级、视图、排序、设置和删除等命令的图标语义。
- 移除盒子左侧颜色条。菜单中的「强调色」现在仅控制交互反馈颜色：搜索与展开按钮激活态、搜索框边框/光标、活动标签页、拖放与排序预览等，不再改变盒子的静态颜色条。

## 流畅度与稳定性

- 盒子高度动画和滚动动画统一到按需启用的帧时钟；没有动态效果时不再持续计时或刷新。
- 滚动、展开/收起和项目悬停采用局部脏矩形更新，避免每帧上传整块显示器位图，降低低帧率与偶发卡顿。
- 图标加载移至后台执行；Shell 状态轮询移至专用 STA 工作线程，桌面主线程不再在计时器回调中执行 Shell/注册表读取。
- 诊断日志改为异步批量写入，频繁的悬停与几何诊断默认不再阻塞 UI 绘制。
- 打开菜单时改为延迟配置二级菜单和缓存 Lucide 字体，减少首次打开的同步工作量。
- 盒子拖拽、缩放结束后只提交前后位置涉及的局部区域；交互区域更新不会再额外请求整层桌面图标重绘。
- 拖动桌面图标保存位置时保留现有 Shell 图标缓存，修复松开鼠标后整个桌面图标看起来重新加载或闪烁的问题。
- 分层窗口提交优化为连续内存复制，并保留首次呈现或系统调用失败时的全量回退，兼顾性能和兼容性。

## 交互修复

- 修复鼠标悬停到标题栏时图标先消失再出现的单帧闪烁。
- 修复拖动盒子、图标或调整盒子尺寸时标题栏按钮突然隐藏的问题。
- 修复鼠标处于盒子正文、标题栏、标签页或标题栏按钮时，悬停状态判定不一致的问题。
- 修复呼出盒子菜单时的额外全层刷新，减少菜单打开瞬间的卡顿。
- 修复桌面在盒子悬停过程中周期性闪烁的问题。
- 修复搜索输入期间触发不必要的全工作区刷新；筛选变化现在只更新受影响的盒子区域。

## 内部改进与验证

- 新增统一动画帧时钟、帧耗时统计、异步诊断写入、Shell 状态监视器、盒子项目搜索过滤器及局部图层渲染支持。
- 新增并扩展标题栏布局、菜单间距、二级菜单行为、图标 DPI 对齐、局部脏区域、动画帧时钟、Shell 轮询和分层窗口复制等自动化测试。
- Release 验证通过：`CrabDesk.Tests` 222 项、`CrabDesk.WinUI.Tests` 181 项；解决方案构建成功，0 个错误。
- 构建仍保留 21 个既有 `MVVMTK0045` WinRT AOT 兼容性警告，本次更新未新增构建错误。
