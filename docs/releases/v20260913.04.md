# CrabDesk 20260913.04

本版本对比线上最新版本 `v20260913.03`，修复 AI 分类对思考类模型必现失败（#2）与桌面接管断开后不自动重连（#3）两个用户反馈问题。

## AI 分类修复（#2）

- DeepSeek 端点默认附带 `thinking: disabled`，避免思考模式耗尽 `max_tokens` 导致空响应；其他 OpenAI 兼容端点不受影响。
- max_tokens 预算提高至 `Clamp(256+48n, 512, 16384)`，长文件名大批量分类不再被默认额度截断。
- 检测 `finish_reason=length` 后自动以 4 倍额度重试（最多 3 档）。
- AI 操作失败提示透出截断或 HTTP 状态码等具体原因。

## 桌面接管自动重连（#3）

- 接管失败后按 2s/5s/15s/30s/60s/120s 退避自动重试；宿主恢复事件到达时立即重试。
- 用户主动暂停时取消自动重试。
- 重试派发接入 UI 线程 watchdog。
