# CrabDesk 20260922.01

本次更新基于 `v20260913.04`，重点改进 AI 整理体验、规则整理、桌面文件刷新与拖放，并新增桌面响应诊断工具。

## 新增与改进

### 对话式 AI 整理工作台
- 整理请求、运行状态与助手回复按对话顺序展示，便于查看每轮整理过程。
- 完成的回复保留该轮过程信息和结果，便于回看。
- 模型与分类设置集中到设置对话框；分类预览支持卡片与 JSON 切换，较长结果可滚动查看。
- 改进运行状态显示、视图切换高亮和部分兼容服务的分类请求处理。

### 桌面响应诊断
- 新增「诊断」页，对比空闲基线、普通文件夹、桌面文件夹与 CrabDesk 的响应耗时，辅助排查卡顿。
- 展示 Shell 扩展信息供排查参考；测量结果和扩展清单不代表已确定某个扩展是故障原因。
- 诊断可能短暂创建并清理测试文件，不会自动禁用扩展或修改系统设置。

### 盒子外观与创建体验
- 从桌面右键菜单创建盒子时，优先放置在点击位置，并限制在可见区域内。
- 默认字体调整为 Microsoft YaHei UI，改善中文显示。
- 修复盒子标题显示为子标签名称的问题，标题栏保持显示盒子自身名称。
- 修复「显示外边框」开关不生效的问题，支持调整边框宽度与浓淡。

## 规则整理
- 修复整理后残留自动生成空盒的问题，按实际存在的项目判断内容；手工创建的空盒不自动删除。
- 改进同名盒子复用，减少重复创建。
- 移除默认的「其它」兜底规则，不匹配规则的文件保留在桌面；启动时清理遗留的默认兜底规则。

## 桌面文件与图标
- 改进保存到桌面后的图标刷新，覆盖隐藏属性变化、通知溢出和临时文件改名保存等情况。
- 修复亚克力桌面层阻挡外部文件拖入空白区域的问题。
- 改进与资源管理器的拖放完成通知，并恢复桌面文件拖向其他程序的拖放入口。
- 外部文件拖到桌面默认按移动处理，包括跨盘拖入；需要复制时请按住 **Ctrl**。
- 调整已保存图标布局的使用策略，优先保留已有布局；显式排序或刷新仍可触发重新排列。
- 为桌面图标间距增加下限，改善部分缩放设置下图标与文字过于拥挤的显示。

## AI 分类稳定性
- 改进部分思考类模型和兼容服务的请求参数处理。
- 增强响应截断的识别与重试处理。
- 修复部分后台状态更新引发的界面线程问题。

## 验证

- 本次 Release 配置测试共 **1098 项通过**：核心测试 400 项、WinUI 测试 652 项、安装器测试 46 项。
- 已验证新构建可启动并接管桌面，日志确认新的图标间距生效；尚未覆盖所有显示器、缩放和 Explorer 重启组合。
