# 桌面小组件（初版）

设置中心侧栏选择“小组件”，或从桌面右键的 CrabDesk 子菜单选择“桌面小组件”。首页以预览卡片展示组件，支持搜索及“全部”“已添加”“未添加”筛选。

组件卡片和编辑面板使用对应类型的彩色图标。天气摘要会随实况显示晴天、夜间、云、雨雪等彩色天气图标；文件中转站显示文件的 Windows 图标，添加页中的示例文件使用相应类型的彩色图标。

组件内部也使用彩色填充图形和信息分组配色：控制中心按功能显示开关与音量、亮度图形，硬件监控的 CPU/GPU/内存/磁盘各有对应颜色，网络区分下载与上传。待办、翻译、天气指标、媒体缺省封面和文件中转站空状态使用同套内容图标。管理页预览与桌面卡片同步展示，用户的字体设置和操作方式保持一致。

紧凑网速组件使用单层背景，两行速度之间保留间距，彩色方向箭头直接与数字对齐。

网络监控的自动模式优先选择带网关的以太网、Wi-Fi 或移动网络连接；可以在组件设置中手动选择需要监测的适配器。

- 未添加的组件使用示例预览，点击后创建组件并进入详情。新建便签、待办、翻译和文件中转站保持空白，天气需要自行选择城市，监控组件添加后开始实时采样。
- 已添加实例展示实际内容，点击进入独立的组件详情。宽窗口左侧为预览，右侧为分组设置；窄窗口上下排列。
- 顶栏的返回入口恢复组件列表及浏览位置；“外观设置”进入共享材质的二级页面，从详情进入后可返回原详情。
- 名称、尺寸、显示器和锁定位置集中在“卡片设置”中，支持自由尺寸的组件默认展开此分组。设置区域独立滚动，末尾提供移除入口，更改自动保存并更新预览。
- 列表卡片按窗口宽度自动换行；移除某类组件后恢复其添加卡片。旧版本已有的同类实例保留内容并分别显示。

## 桌面操作

时钟提供默认的 180 × 180 DIP 方形卡，以及 288 × 120 DIP 横向卡。方卡显示居中放大的指针表盘；横向卡左侧为 100 DIP 表盘，右侧为数字时间与日期星期，开启秒针时数字时间也显示秒数。升级时旧小号方卡转换为标准方卡，旧横卡转换为横向卡，保留位置、锁定与秒针设置。可在卡片的“尺寸”菜单或管理页中切换布局。

- 拖动卡片标题移动位置；时钟可直接拖动。拖到另一块显示器后松手，位置按目标屏幕 DPI 换算并限制在工作区内。管理页也可选择显示器。
- 悬停时右上角显示菜单。右键卡片可编辑、锁定、切换尺寸；月历可回到本月，天气可手动刷新。
- 单击桌面卡片不会打开设置页。便签点击正文直接编辑，待办左侧复选框直接切换完成状态，翻译在卡片内直接操作，天气正文展开独立详情面板，底部箭头切换城市。右键卡片选择“组件设置”，或从管理页点击对应预览卡片，可调整组件选项。
- 月历顶栏箭头切换月份，“今”返回本月。悬停日期时在鼠标附近显示农历、节日与节气；宽卡右侧显示近期节日和节气倒数日。
- 管理页可修改卡片名称、尺寸和显示器等设置。移除组件需要确认，组件内容随实例移除。

## 便签

点击桌面便签正文直接输入或粘贴多行文字，支持中文输入法、选中、复制、粘贴和滚动阅读。Enter 换行，Esc 或点击其他区域收起输入框，内容自动保存；再次点击可继续编辑。右键“编辑便签”也可进入卡片内编辑。锁定位置只限制拖动，仍可编辑正文。

设置页保留便签名称、尺寸、显示器和位置锁定选项，正文在桌面卡片中查看和编辑。移动、调整尺寸、移除或暂停接管时收起输入框，保留已输入内容。

## 待办

点击顶栏“+”添加条目，Enter 保存、Esc 取消。悬停条目后，右侧显示日期、编辑与删除按钮。开始和截止日期均可留空；填写日期后在条目下方显示范围。未完成条目优先显示，已完成条目集中到可展开的分组中。

删除按钮会在附近打开确认气泡，展示条目摘要，点击“删除”后才移除。点击“取消”、按 Esc 或点击气泡外部均保留条目。

## 文件中转站

将多个文件拖到桌面或悬浮文件中转站，点击组件左上角的“+”或空列表中的添加区域，也可在组件设置中点击“添加文件…”，即可收集文件。拖入时，列表区域会高亮并显示松开后的收集方式。设置中的“新文件的收集方式”提供两个选项：

- **引用原文件**：保存原文件路径，打开和拖出使用原文件。原文件移动或删除后，条目标为不可用。
- **复制到中转站**：将文件复制到配置目录下的 `FileShelf` 文件夹，保存独立副本。每个组件和条目使用独立目录，允许同名文件同时存在。打开和拖出使用所保存的副本，原文件保持原位置。

切换收集方式只影响后续添加；已有条目保留各自的方式，因此同一个中转站可以同时包含引用和副本。文件复制期间显示操作状态，完成后显示文件数量；部分文件失败时保留成功添加的条目并提示原因。

在中转站设置中打开“全局悬浮中转站”，或在桌面组件的右键菜单中开启，即可在其他应用上方使用。同一中转站的桌面组件和悬浮窗口共用文件列表；关闭悬浮窗口只关闭这个显示入口，文件仍保留。暂停桌面接管时，已开启的悬浮窗口继续可用。

拖动悬浮窗口标题可调整位置，位置会自动保存。开启“贴边自动收起”后，拖到屏幕左、右、上或下边缘会吸附，移开鼠标后收成小标签；悬停标签或向标签拖入文件即可展开。窗口上的图钉用于保持展开；设置中的“重置悬浮位置”可将窗口移回可见区域。位置按显示器和缩放比例保存，显示器变化后会调整到当前工作区内。

单击选中文件，Ctrl 单击切换单个选择，Shift 单击选择范围；将选中的多个文件拖出，可放入资源管理器或支持文件拖放的应用。双击打开文件，右键提供打开、打开所在位置、复制路径和移除；列表内容较多时使用滚轮浏览。不可用条目仍显示名称及状态，可移除后重新添加。

列表显示文件名、引用或副本状态及来源文件夹；底部显示已选数量，右侧滚动指示提示列表位置。标准字号显示三行文件，放大字号后行高随之增加。桌面组件与设置预览使用相同的布局尺寸。

移除副本条目、清空中转站和移除组件都需要确认；确认框会说明将清理的副本。仅删除中转站管理的副本，原文件保留。移除引用条目只清理所记录的路径。文件中转站正在处理文件时，等待完成后再清空或移除组件。

条目的原路径、收集方式和副本相对路径随 `config.json` 与布局备份保存。布局备份只包含条目元数据，复制的文件内容不会嵌入备份；迁移到其他电脑时，如需保留副本，应同时迁移配置目录下的 `FileShelf` 文件夹。引用仍需要原路径可访问，缺失的副本会显示不可用。

## 外观与保存

卡片新建时默认使用不透明的黑白实色外观。特色主题中，时钟、天气、性能监控、网络监控和控制中心使用近黑背景，月历、便签、待办、翻译和文件中转站使用纯白背景；也可明确选择浅色或深色主题。浅色为纯白，深色为近黑，月历深色为纯黑。颜色用于内容图标、天气图形、数据曲线、进度与交互状态。监控卡片以读数为主，控制中心通过中性面板明度与开启状态的功能色组织层次。这些卡片中原先沿用全局外观的实例保留该设置。

组件页顶栏右侧的“外观设置”进入二级页面，统一设置组件亚克力来源。默认开启“跟随盒子”，背景色、强调色、不透明度与模糊效果使用盒子设置；关闭后统一设置组件背景颜色、不透明度（0–100%）与模糊强度（0–100%），强调色沿用盒子。独立参数在切换来源后保留。返回后保留组件列表的搜索、筛选和浏览位置。

点击组件进入独立详情布局，宽窗口左侧为组件预览、右侧为常显的分组卡片，窄窗口上下排列。外观风格、字体设置与卡片设置各自成组，设置区域纵向滚动。顶栏可返回组件列表，预览随设置更新。详情中的“背景材质”提供“实色”和“亚克力”。实色可选择“组件特色”“浅色”“深色”主题，切换材质保留实色主题选择；黑白背景始终不透明。亚克力复用原有组件样式，保留独立表盘、内容面板、输入区域与功能配色。全局选择跟随盒子时取第一个盒子的外观，没有盒子时取默认盒子外观。

歌词组件的“背景模式”在“亚克力”和“透明”之间切换，默认亚克力；使用与其他亚克力组件相同的“组件亚克力”设置。透明模式仅显示歌词与播放器信息，原有透明选择会保留。组件的右键菜单与弹出卡片（控制中心详情、音量合成器、麦克风、歌词滑块、待办删除确认等）跟随所属组件的背景色、强调色和不透明度，独立弹窗的模糊由系统材质提供。所有组件共用组件圆角与全局外边框，标准卡 180 × 180 DIP。

组件页“外观设置”中的“组件圆角”支持 0–20 DIP，0 为直角，默认 8 DIP；同时应用于实色与亚克力组件，独立于盒子圆角。桌面、管理页预览、亚克力裁切与原生窗口区域使用同一参数。旧配置从原有圆角初始化，更改自动保存并随备份恢复。

毛玻璃使用现有 Windows 桌面材质宿主；不支持或系统关闭透明效果时，独立亚克力组件使用同配色的不透明背景，跟随盒子的组件与盒子使用相同回退。组件随桌面接管暂停/恢复、Explorer 重连及显示器变更一起恢复。

位置、尺寸、锁定、便签、待办、翻译内容和天气缓存自动保存在本机 `config.json` 中，布局备份与恢复包含组件数据。旧配置没有组件时保持空列表。

便签和待办支持自由调整宽高：拖动卡片四条边或四个角即可拉伸，最小为 180 × 120 DIP，最大不超过当前显示器工作区。锁定位置时禁止拖拽调整尺寸。也可在组件设置的“卡片设置”中输入宽、高后点击“应用尺寸”，或用尺寸菜单恢复预设。调整只改变卡片边界，文字字号保持不变；便签重新换行、待办按可用高度显示列表，超出内容仍可滚动。自定义尺寸随配置和布局备份保存。

## 翻译

在“小组件”中选中翻译卡片，可直接配置专用的 HTTPS AI 接口、API Key 和模型，支持 OpenAI 兼容接口。桌面卡片右键“配置 AI 接口”也打开此设置面板。翻译配置独立保存；升级时将原有接口和模型一次性迁移到翻译配置，之后两边分别修改。API Key 使用独立的本机加密文件保存，布局备份不包含密钥，恢复布局保留本机翻译配置。

点击桌面卡片左侧原文区可直接输入或粘贴多行文字；右上角选择目标语言，点击底部“翻译”或按 Ctrl+Enter 提交。Enter 换行；Esc 或点击其他区域收起输入框并保留已输入内容。右侧显示译文，滚轮阅读长译文，“复制”写入剪贴板；请求期间“翻译”变为“取消”。

翻译设置支持修改提示词，使用 `{targetLanguage}` 代入目标语言。默认提示词要求保留原文格式，避免给没有句末标点的短语额外添加标点。可开启会话复用并设置空闲后自动新建会话的分钟数；会话仅在内存中保存，切换语言、接口配置或达到上下文限制时会自动重置。

打开卡片、输入文本、修改接口配置和切换语言不会调用接口；主动翻译后才发送原文和目标语言。单次原文上限 12,000 字符。

修改原文或目标语言后，清空旧译文以免混淆；打开已有翻译实例保留保存的译文。失败时显示原因并允许重试。实际接口的访问权限、模型可用性与用量费用由所配置的服务决定。

## 天气

在“城市管理”的“添加城市”中输入中文或英文城市名，按 Enter 或点击搜索图标，再从候选项中选择正确的地区即可添加。搜索无结果或失败时在输入框下方提示，可直接修改名称重试。同一个组件可保存多个城市，各自保留天气缓存；“桌面显示城市”下拉列表、桌面卡片底部箭头及右键“切换城市”都可以选择当前城市。下拉框旁的移除按钮需要确认，移除城市不影响其他城市，旧版本单城市配置自动迁移。天气摘要与刷新入口集中在“天气状态”中。

未添加城市时点击正文中的“使用当前位置”，或通过右键菜单的“使用当前位置”，即可获取当地天气。方形卡片标题左侧仍保留定位图标；宽版卡片不再显示定位与位置管理图标，统一从右键菜单进入。右键卡片同样提供“系统定位设置”入口。卡片显示正在定位、未授权和失败状态；定位期间继续展示已有天气，手动城市保持不变。定位按钮与标题拖动区域分开，锁定位置后仍可定位。

定位由 Windows 获取坐标，再通过小米天气解析地区名称，首次使用需要系统授权；必要时在卡片正文位置显示短暂的位置授权提示。组件设置中的“使用当前位置”复用同一流程。服务关闭、拒绝授权或定位超时时仍可手动添加城市。每次点击更新同一个“当前位置”条目，不在后台持续定位。

城市配置后，每 30 分钟更新当前城市天气；切换城市时优先使用其缓存，手动刷新可立即请求。失败后保留上次天气并显示失败状态，至少等待 5 分钟再自动重试。未配置城市和首次加载时显示对应提示，不展示示例天气。

方形天气卡显示体感温度、湿度、风速和 AQI。宽版上方横向排列天气图标、当前温度、最高/最低温与城市，下方显示未来六个小时的时间、天气图标和温度；宽版顶部只保留城市名用于切换城市，定位与位置管理改由右键菜单进入。没有逐小时数据时显示空状态。点击正文或右键“天气详情”展开独立面板，可切换已保存城市和刷新，查看气压、紫外线、日出日落、PM2.5、风向、逐小时气温与 AQI 曲线、未来七天高低温/降水概率，以及接口提供的天气预警和生活指数。曲线可横向滚动，面板可纵向滚动；关闭按钮或 Esc 收起详情。

小时气温与 AQI 使用各自刻度；日期和小时保留预报城市的时区。接口缺失的观测值显示“—”，没有预报数据的分区不显示。丰富数据随每个城市的天气缓存保存，旧缓存可读取，首次展开时会补充请求完整预报。

城市搜索、位置反查和天气数据使用小米天气 v3 接口，请求参数参考 [CrabTab 的天气接入](https://github.com/yixing233/CrabTab/blob/main/src/utils/weather.ts)。旧版 Open-Meteo 缓存保留原来源标记，刷新后显示小米天气；接口失败时保留已有真实缓存。

## 性能监控与网络监控

性能监控每秒采样整台电脑的 CPU、GPU、物理内存和磁盘。GPU 采用最繁忙引擎的占用率；磁盘活动、读写速率为物理磁盘汇总，容量为固定盘合计。方卡显示占用率与进度条，宽卡增加内存用量和磁盘读写速度。右键可查看完整容量和读写数据。首轮采样及缺失的计数器显示“—”，不需要管理员权限；GPU 数据取决于系统和驱动提供的计数器。

网络监控默认按系统路由选择活动适配器，也可在设置中选择指定网卡。上下行由该网卡的字节计数按实际采样间隔换算，不叠加虚拟与物理网卡；切换接口、计数器重置或休眠恢复时重新建立基线。断线会显示未连接状态。

详细视图在网速和连接状态下显示当前流量最高的三个进程。点击桌面卡片中的“下载 / 上传”，或在编辑页和右键菜单中选择排序方向；选择会自动保存。进程排行使用 ETW 采集全部网卡的 TCP/UDP 流量（含 IPv4/IPv6，排除本机回环），范围与所选网卡的总网速不同，两者数值无需相加一致。仅在详细视图中运行采集，切换样式、移除组件、暂停或退出时释放采集会话。Windows 要求管理员权限；普通权限下继续显示网速与延迟，排行区显示权限提示。首次采集、当前方向无流量及采集不可用分别显示对应状态。进程名称和流量仅存在内存中。

本机地址、网关的复制与公网 IP 按需查询保留在右键菜单中。

在组件设置或右键“显示样式”中选择：完整信息、仅上下行速度、上下行曲线图。简洁版仅显示下载/上传速率，提供 180 × 84 DIP 小卡与 372 × 84 DIP 横条；曲线版为 372 × 180 DIP，同时显示当前速率与最近 60 秒的两条曲线，上下行共用刻度。漏采时断开曲线，切换接口或断网后清除旧记录，首轮显示等待采样。历史仅保存在内存中。

延迟默认测量 `1.1.1.1`，约每五秒探测一次。可输入 IP 或主机名，按 Enter 或离开输入框保存；留空使用网关。延迟探测与公网 IP 查询采用系统路由，不绑定所选网卡。目标拒绝 ICMP 或超时时显示实际状态。

本机 IPv4/IPv6 显示在完整信息卡片内；右键可复制完整地址和网关。点击完整卡片底部“公网 IP”条或设置中的查询按钮，通过 ipify 查询当前系统出口地址；不会自动轮询。查询失败可点击重试，切换接口或断线后清除旧结果。监控快照、历史速率和 IP 地址仅在内存中保存，配置与备份只保存组件位置、显示样式、所选网卡和延迟目标。

## 设计与验证

控制中心在亮度滑块下方提供“亮度 · 显示器”选择行，可选择当前连接的屏幕。默认调节组件所在屏幕；选择后保存目标并重新读取该屏幕亮度，滑块只向此屏幕发送调节请求。外接屏使用 DDC/CI，内置屏按设备标识匹配 WMI；不支持调节或所选屏幕断开时显示不可用，不转而调节其他屏幕。

控制中心的“编辑快捷操作”可添加“网卡”。点击后列出系统中的物理和虚拟网卡，分别显示启用状态与连接状态，支持逐张启用或禁用。禁用的网卡仍保留在列表中，可再次开启；更改状态时请求 Windows 管理员授权，完成后回读实际状态。详情卡片沿用组件背景，支持手动刷新和打开网络设置。

卡片尺寸、材质及配色依据[桌面小组件设计规范](design/desktop-widgets.md)。设计 HTML 是外观参照，实际功能由桌面运行时和 WinUI 管理页提供。

测试覆盖旧配置兼容、保存恢复、备份、月历日期、接口请求与错误、换行规范化、纯组件桌面命中区域、DPI/圆角渲染和锁定/拖动。在线翻译端到端验证需要实际配置的服务凭据。
